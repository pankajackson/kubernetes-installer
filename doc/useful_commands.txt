Check All Properties: 
    vboxmanage list systemproperties
Update Machine Directory: 
    vboxmanage setproperty machinefolder /home/jackson/VirtualBox\ VMs
List Host-Only Adapter: 
    vboxmanage list hostonlyifs
Create a new Host-Only Adapter: 
    vboxmanage hostonlyif create
Update a new Host-Only Adapter: 
    VBoxManage hostonlyif ipconfig vboxnet0 --ip 10.0.0.2 --netmask 255.255.255.0
Delete a new Host-Only Adapter: 
    VBoxManage hostonlyif remove vboxnet0
List VMs:
    VBoxManage list vms
Delete VMs:
    VBoxManage unregistervm --delete <UUID_or_Name>

    sudo apt-get install locales -y
    sudo locale-gen en_IN.UTF-8
